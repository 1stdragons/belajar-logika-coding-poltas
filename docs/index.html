🚀 Mulai Belajar Sekarang

Langkah 1: Install Plugin Claude Code di VS Code

1
Buka VS Code > Extensions (Ctrl+Shift+X) > Cari Claude Code by Anthropic > Install
2
Atau install via command line, klik Copy:
code --install-extension Anthropic.claude-code

Langkah 2: 3 Checkpoint Wajib (Biar Gak Asal Copy)

1
Checkpoint Logika: Jelaskan dulu alurnya pakai bahasa sendiri sebelum minta AI nulis. Misal: "Saya mau bikin if umur > 18 maka...".
2
Checkpoint Baca: Setelah AI nulis, baca baris per baris. Tanya: variabel ini buat apa? Kenapa pakai loop ini?
3
Checkpoint Uji: Ganti 1 angka, jalankan. Kalau error, tanya AI kenapa error, jangan langsung minta benerin.

Langkah 3: Prompt Template Mahasiswa Poltas

Pakai template ini kalau minta bantuan AI, biar belajar logikanya:

Saya mahasiswa D3 TI Poltas. Saya sedang belajar logika [sebutkan topik: percabangan/looping/array]. Tolong JANGAN langsung kasih kode jadi. Bantu saya dengan: 1. Jelaskan logikanya langkah demi langkah 2. Kasih pseudocode-nya saja 3. Baru kasih contoh kode sederhana + penjelasan per baris Topik saya: [tulis topik kamu di sini]
