# Belajar Logika Coding - Poltas
### Komputasi Cerdas | Keamanan Data | D3 TI Politeknik Aceh Selatan
**Intelligence Secured, Future Unlocked**

> Adaptasi edukasi dari [nykooi1/vibe-wise](https://github.com/nykooi1/vibe-wise) untuk Mahasiswa D3 Teknik Informatika Politeknik Aceh Selatan.
> Slogan: **Kamu yang Mikir, AI yang Nulis.**

#### Kenapa Repo Ini Dibuat?
Mahasiswa sering langsung suruh AI bikin kode tanpa paham logikanya. Repo ini membalik prosesnya:
AI akan bertanya dulu ke kamu: "Gimana logikanya kalau begini?" - Kamu harus jawab dulu baru AI boleh nulis kode.

#### Cocok Untuk Mata Kuliah:
- Algoritma & Pemrograman
- Basis Data
- Rekayasa Perangkat Lunak
- Proyek Akhir

#### 3 Tahap Belajar (Checkpoint Wajib)
1.  **Build Checkpoint:** Diajak mikir alur. Contoh: "Jika data mahasiswa ada di 2 kelas, kalau kelas A dihapus, data mahasiswanya gimana?"
2.  **Design Checkpoint:** Diajak milih struktur. "Mau pakai tabel penghubung atau gimana? Setuju?"
3.  **Implementation Checkpoint:** AI baru nulis kode + jelasin kodenya.

#### Cara Pakai Untuk Mahasiswa (Gratis - MIT License)
1. Install Claude Code & Python 3
2. Di Claude Code ketik:
   /plugin marketplace add 1stdragons/belajar-logika-coding-poltas
   /plugin install belajar-logika-coding-poltas@vibe-wise
3. Restart Claude Code, lalu ketik `/vibe-wise:learn`
4. Pilih level: Beginner / Intermediate / Advanced

#### Aturan Main di Kelas Pak Fardian:
- Dilarang `Implement this step` sebelum bisa jelaskan logikanya dengan bahasa sendiri.
- Folder `.vibe-wise/` wajib di-ignore, jangan di-push ke GitHub.
- Tetap cantumkan lisensi MIT asli.
